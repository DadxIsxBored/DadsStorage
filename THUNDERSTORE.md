# Thunderstore release

Run `.\build.ps1 -Package` from the repository root. Upload the single ZIP produced in `dist`.

The package contains `DadsStorage.dll`, `manifest.json`, `README.md`, `CHANGELOG.md`, `icon.png`, `LICENSE`, and `NOTICE` at its root.

The package name is `DadsStorage`, the initial version is `1.0.0`, and the only required Thunderstore dependency is BepInExPack for Valheim.
